# 数据浏览设计

> 后续修改数据记录、历史查询或曲线界面的 agents 请继续维护本文档，保证文档与程序实际行为一致。

## 1. 数据来源与存储

- 子板完成一次有效轮询后，`DataLogger` 按 `recordIntervalSec` 记录 CSV，默认周期为 1 秒。
- CSV 按天分文件，路径为 `dataPath/YYYY-MM-DD.csv`。
- 每条记录包含时间、RS485 端口、子站 ID、子板名称、设备类型和 JSON 数据。子板的稳定唯一键是 `portIndex + slaveId`。
- 文件由保留天数和总容量上限共同轮转，不使用数据库。

## 2. 子板筛选列表

历史页的下拉列表合并两类来源：

1. 本次运行已自动发现的子板。
2. `dataPath` 下 CSV 文件中出现过的端口和子站 ID。

因此，子板当前离线或尚未被自动扫描到时，仍可以查看它的旧数据。只存在于 CSV 的条目标记为“历史”，但不禁用选择。同一 ID 位于不同 RS485 端口时是两个独立条目。

CSV 子板索引只在进入数据浏览页时重载。自动发现列表变化时只合并内存数据，不重复扫描全部 CSV，避免大量历史文件导致界面卡顿。

## 3. 单块子板模式

选择具体的 `P端口 / ID` 后：

- 查询只返回该子板的记录。
- 曲线按时间连续显示该子板的三路温湿度计平均温度、平均湿度和两路 PT100 平均温度。
- 表格显示该子板最新 500 条查询明细。

## 4. 全部子板模式

“全部子板”不直接把不同子板的点连成一条线，而是先按整秒聚合当秒可用样本：

- 每块子板先计算自身三路温湿度计的平均温度。
- 主温度曲线显示各子板平均温度的总体平均值。
- 橙色半透明范围带显示当秒子板平均温度的最低值到最高值。
- 湿度曲线显示当秒各子板平均湿度的总体平均值。
- PT100 曲线显示当秒各子板两路 PT100 平均温度的总体平均值。
- 点击曲线时，详细信息同时显示温度范围和当秒参与聚合的记录数。
- 表格不做聚合，仍保留每块子板的原始明细，最多显示最新 500 条。

结果摘要分别显示“原始明细数”和“聚合时间点数”，避免将两者混淆。

## 5. 最新数据与历史拖动

- 日期或子板查询后，曲线默认定位到最新时间。
- 视图位于最右侧时，新记录会自动追加并跟随最新。
- 用户左右拖动查看旧数据后，新数据不抢回视图位置。拖回最右侧即恢复自动跟随。
- 已建立页面缓存且日期范围、子板筛选均匹配时，新写入的记录由 `recordAppended` 直接追加；即使当前切到其他页面也不需重新扫描 CSV。

## 6. 页面缓存与读盘时机

- 程序启动时不立即查询历史数据，首次进入数据浏览页时才加载子板索引和当前查询条件。
- 查询结果、聚合曲线和最新 500 条表格明细保留在内存中。切换到其他页后，新写入记录仍按当前日期/子板条件增量更新该缓存。
- 再次进入数据浏览页直接显示缓存，不重读 CSV。
- 日期或子板条件改变后点击“查询”才重新读取匹配文件。相同条件重复点击“查询”只恢复跟随最新，不重复读盘。

## 7. 触摸屏交互

- 水平时间滚动条高度为 36 px，拖块最小宽度为 100 px。
- 子板下拉列表最多同时显示 7 项，使用 36 px 宽的竖向触摸滚动条。
- 曲线支持拖动时间轴与点击查看交叉线详情。
- “仅看表格”用于小屏幕上将空间集中给明细数据。

## 8. 性能边界

- CSV 子板索引只解析前固定列，不解析 JSON 数据，用于减少进入页面时的成本。
- 当前历史查询仍会将日期范围内的匹配记录读入内存，表格虽只显示 500 条，但曲线保留全部查询点。在 1 秒周期、多子板和长日期范围组合下，后续需考虑流式聚合或曲线降采样，避免内存随记录数线性增长。
