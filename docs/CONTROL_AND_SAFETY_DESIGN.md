# 温控、自检与备用引脚设计

## 1. 面向操作员的行为

- 上电后顶部状态显示“温湿度自检中”。三路温湿度数据齐全且合理后显示系统正常。
- 任一探头超出绝对量程，或等待时间结束后仍缺数据时，弹出明确的端口、子板 ID 和故障原因。三路测点允许处于不同位置，不做相互偏差判断。
- 自检故障会停止自动温控、关闭 OT3/OT4、点亮对应子板红灯。故障未恢复前，该子板的手动 OT3/OT4 也被拦截。
- 为防止接触不良造成告警闪烁，数据连续 3 次正常后才解除自检故障。
- 高压联锁仍是最高优先级，会覆盖温湿度自检和普通模式指示。

## 2. 固定阈值模式

固定阈值模式保持需求文档原规则：

| 平均温度 | OT3 | OT4 |
| --- | --- | --- |
| 低于目标减下限回差 | 开 | 开 |
| 高于目标但未超过上限回差 | 开 | 关 |
| 高于目标加上限回差 | 关 | 关 |

回差区内维持当前输出，所有变化仍受“继电器最短切换间隔”保护。

## 3. PID 两级输出模式

现场执行器是两路机械继电器，不能使用高频 PWM。PID 因而先计算 0～100% 的加热需求，再映射为两级输出：

| PID 需求（默认输出点） | OT3 | OT4 |
| --- | --- | --- |
| < 10% | 关 | 关 |
| 10%～< 60% | 开 | 关 |
| ≥ 60% | 开 | 开 |

默认参数为 Kp=12、Ki=0.15、Kd=0。10% 一级点和 60% 二级点均可调整。积分带限幅和饱和保护，继电器输出仍受最短切换间隔保护。默认关闭微分项，避免温湿度数字探头的跳动放大为输出抖动。

PID 参数必须在现场以空载、小功率负载、正式负载的顺序整定；整定前可继续使用固定阈值模式。

## 4. 温湿度自检默认值

| 检查项 | 默认值 |
| --- | --- |
| 初始化宽限 | 60 秒 |
| 温度有效范围 | -40～85 ℃ |
| 湿度有效范围 | 0～100 %RH |
| 自动恢复 | 连续 3 次正常 |

控制模式、PID 参数/输出点、自检等待时间和绝对量程都在参数设置页配置并立即应用，操作员无需编辑配置文件。
保存时会自动整理反向填写的最小/最大量程和 PID 一级/二级输出点，避免生成无效区间。

## 5. 备用引脚

- OT1、OT2、OT5、OT6 各自可在前端选择：安全关闭、手动控制、跟随自动运行、跟随报警。首次发现子板时，手动模式也先初始化为关闭；后续不会被普通状态刷新覆盖。
- 备用输入 0x0002 可选择仅监视、高电平联锁或低电平联锁。联锁触发时停止自动温控、关闭 OT3/OT4、点亮故障子板红灯；解除后必须由操作员重新启动。
- 高压、温湿度自检和备用输入联锁始终优先于 OT3/OT4 手动/自动控制。备用输出的“跟随报警”覆盖这三类报警。
