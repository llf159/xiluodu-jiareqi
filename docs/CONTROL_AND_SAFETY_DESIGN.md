# 温控、自检与备用引脚设计

## 1. 面向操作员的行为

- 上电后顶部独立显示 60 秒自检倒计时；极端值故障时改为醒目红色通知，恢复期显示连续 3 次正常确认的剩余次数。
- 三路测点允许处于不同位置，不做相互偏差判断；缺数据只保持“数据未齐”通知，不报故障。只有读数超出固定极端量程时才报警。
- 自检告警不停止整体自动温控、不关闭或拦截手动 OT3/OT4。自动调度只排除超出固定量程的温度值，仍用同一子板剩余正常探头的平均值运行；没有任何正常温度时才跳过该子板本轮调度。不使用阻塞式弹窗；顶部通知和子板红灯负责醒目提示。
- 高压联锁仍是控制安全的最高优先级；顶部自检通知独立保留，不与运行状态互相覆盖。高压检测源可配置为数字量 `0x0001`（0 或 1 触发）或模拟量 `0x0003`（原始值除以 10 后按电压阈值触发），默认保持模拟量。

## 2. 温度目标来源

- 默认目标为每块子板内部 PT100-1、PT100-2 中有效读数的平均值，外部三路温湿度探头的有效温度平均值作为被控量，因此控制的是外部温度对内部温度的跟随。
- PT100 控制有效范围固定为 -40～85 ℃；有一路有效时使用该路，两路均有效时取平均，两路均无有效值时跳过该子板本轮调度。
- 操作员也可选择固定目标温度；只有选择固定目标时才显示固定温度参数。阈值和 PID 两种控制模式共用目标来源；防凝露模式不使用目标来源。

## 3. 固定阈值三档模式

默认按 `目标温度 - 外部温度` 的温差分档：

| 温差 | 默认输出 |
| --- | --- | --- |
| < 0.3 ℃ | 全关 |
| 0.3～< 1.5 ℃ | 低功率单路（默认 OT3） |
| 1.5～< 3.0 ℃ | 高功率单路（默认 OT4） |
| ≥ 3.0 ℃ | OT3、OT4 同开 |

三个温差点均可配置并在保存时排序；默认在每个边界两侧使用 0.2 ℃ 回差。回差自动限制为不超过相邻温差点间距的一半，避免相邻档位的保持区重叠。所有变化仍受“继电器最短切换间隔”保护。

## 4. PID 三档输出模式

现场执行器是两路规格不同的机械继电器加热回路，不能使用高频 PWM。PID 因而先计算 0～100% 的加热需求，再映射为三档输出：

| PID 需求（默认输出点） | OT3 | OT4 |
| --- | --- | --- |
| < 10% | 关 | 关 |
| 10%～< 35% | 开 | 关 |
| 35%～< 60% | 关 | 开 |
| ≥ 60% | 开 | 开 |

默认参数为 Kp=12、Ki=0.15、Kd=0，三个输出点为 10%/35%/60%。默认一级单路是 OT3，前端可切换为 OT4；二级自动使用另一路，三级两路同开。积分带限幅和饱和保护，继电器输出仍受最短切换间隔保护。默认关闭微分项，避免数字探头跳动被放大为输出抖动。

PID 参数必须在现场以空载、小功率负载、正式负载的顺序整定；整定前可继续使用固定阈值模式。

## 5. 防凝露三档模式

防凝露是阈值、PID 之外的第三种独立控制模式，选择后不再执行温度控制，只按凝露风险切档：

- 三组外部温湿度分别使用 Magnus 公式计算露点，取最高值作为最不利空气条件；表面温度采用内部有效 PT100 平均值。
- `露点余量 = 内部 PT100 平均温度 - 最不利露点`，按余量三档切档（默认边界 3/2/1 ℃，每档边界两侧使用 0.2 ℃ 回差，回差同样限制在相邻边界间距一半以内）：

| 露点余量（默认） | 输出 |
| --- | --- |
| > 3 ℃ | 全关 |
| 2～3 ℃ | 低功率单路（默认 OT3） |
| 1～2 ℃ | 高功率单路（默认 OT4） |
| ≤ 1 ℃ | OT3、OT4 同开 |

- 无最高档限制：余量足够低时可以直接开到两路同开，单路功率顺序与阈值/PID 模式共用前端设置。
- 外部平均温度超过 PT100 平均值 + 温升上限（默认 5 ℃）时停止加热，避免仅为降低相对湿度而持续升温。
- 前端可调整三个余量边界、切档回差和温升上限。0 %RH 或无完整有效温湿度对时不产生防凝露需求；两路 PT100 均无有效值时跳过该子板本轮调度。

## 6. 温湿度自检默认值

| 检查项 | 默认值 |
| --- | --- |
| 自检倒计时 | 60 秒（固定） |
| 温度有效范围 | -40～85 ℃ |
| 湿度有效范围 | 0～100 %RH |
| 自动恢复 | 连续 3 次正常（固定） |

控制模式和 PID 参数/输出点在参数设置页配置并立即应用；自检量程、倒计时和恢复次数使用固定默认值，不对操作员开放。

## 7. 备用引脚

- OT1、OT2、OT5、OT6 各自可在前端选择：安全关闭、手动控制、跟随自动运行、跟随报警、跟随 OT3 或跟随 OT4。跟随主回路时优先采用本次即将下发的 OT3/OT4 值；本次没有主回路指令时读取该子板当前值，因此不同子板独立同步。首次发现子板时，手动模式也先初始化为关闭；后续不会被普通状态刷新覆盖。
- 备用输入 0x0002 可选择仅监视、高电平联锁或低电平联锁。联锁触发时停止自动温控、关闭 OT3/OT4、点亮故障子板红灯；解除后必须由操作员重新启动。
- 高压和备用输入联锁始终优先于 OT3/OT4 手动/自动控制；温湿度自检只通知不阻塞。备用输出的“跟随报警”仍覆盖这三类报警。
