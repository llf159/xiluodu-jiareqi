# 温控、自检与备用引脚设计

## 1. 面向操作员的行为

- 上电后顶部状态显示“温湿度自检中”。三路温湿度数据齐全且合理后显示系统正常。
- 任一探头超量程、明显偏离另外两路，或 60 秒后仍缺数据时，弹出明确的端口、子板 ID 和故障原因。
- 自检故障会停止自动温控、关闭 OT3/OT4、点亮对应子板红灯。故障未恢复前，该子板的手动 OT3/OT4 也被拦截。
- 为防止接触不良造成告警闪烁，数据连续 3 次正常后才解除自检故障。
- 高压联锁仍是最高优先级，会覆盖温湿度自检和普通模式指示。

## 2. 固定阈值模式

固定阈值模式保持需求文档原规则：

| 平均温度 | OT3 | OT4 |
| --- | --- | --- |
| 低于目标减下限回差 | 开 | 开 |
| 高于目标但未超过上限回差 | 开 | 关 |
| 高于目标加上限回差 | 关 | 关 |

回差区内维持当前输出，所有变化仍受“继电器最短切换间隔”保护。

## 3. PID 两级输出模式

现场执行器是两路机械继电器，不能使用高频 PWM。PID 因而先计算 0～100% 的加热需求，再映射为两级输出：

| PID 需求 | OT3 | OT4 |
| --- | --- | --- |
| < 10% | 关 | 关 |
| 10%～< 60% | 开 | 关 |
| ≥ 60% | 开 | 开 |

默认参数为 Kp=12、Ki=0.15、Kd=0。积分带限幅和饱和保护，继电器输出仍受最短切换间隔保护。默认关闭微分项，避免温湿度数字探头的跳动放大为输出抖动。

PID 参数必须在现场以空载、小功率负载、正式负载的顺序整定；整定前可继续使用固定阈值模式。

## 4. 温湿度自检默认值

| 检查项 | 默认值 |
| --- | --- |
| 初始化宽限 | 60 秒 |
| 温度有效范围 | -40～85 ℃ |
| 湿度有效范围 | 0～100 %RH |
| 单路温度相对中位数最大偏差 | 15 ℃ |
| 单路湿度相对中位数最大偏差 | 30 %RH |
| 自动恢复 | 连续 3 次正常 |

这些值在 config/app.ini 中可按传感器型号和安装位置标定。

## 5. 备用引脚

- OT1、OT2、OT5、OT6：未分配前始终写 0，启动、发现子板、模式切换和告警都会重新落实安全关闭。
- 备用输入 0x0002：只在实时界面与 CSV 中监视，不触发加热、声光或高压联锁。
- 后续若要启用备用输出，应先确定负载类型、上电安全态、有效电平、联锁关系和断线行为，再增加独立配置；不能直接复用现有 OT3/OT4 控制入口。
